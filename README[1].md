# ONE DETAIL — early web prototype

## What's included
- `index.html`: standalone mobile-friendly mystery game
- `manifest.json`: installable web app metadata
- `sw.js`: basic offline caching
- `icon.svg`: app icon

## Test locally
Open `index.html` in a browser. Game progress is saved in that browser using local storage.

## Publish free with GitHub Pages
1. Create a free GitHub account at https://github.com/
2. Create a new **public** repository, e.g. `one-detail-game`.
3. Upload all four files from this folder to the repository root.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your public URL will appear in Settings → Pages.

## Important limitations
- This is an early prototype, not a production-ready commercial release.
- Progress is stored only on the player's device/browser. There are no accounts, cloud saves, leaderboards, analytics, or payments.
- No advertising is installed. Add monetization only after testing player demand and reviewing the relevant platform rules.
- Review and play-test every puzzle before launch. Some cases are logic exercises, not realistic forensic conclusions.
- A custom domain, app-store listing, backend, and payment processing are not included.
